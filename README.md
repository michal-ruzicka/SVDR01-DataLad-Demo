# MRI Anonymise
Demo of the use of [DataLad](https://www.datalad.org/) tool for processing (conversion and anonymisation) of image data from magnetic resonance.

The tracking of data provenance and computational reproducibility, supported by DataLad, is demonstrated.

The repository was prepared for the seminar [*SVDR01 Research Data Management in Practice: Advanced Course for Data Stewards*](https://is.muni.cz/predmet/cus/podzim2025/SVDR01?lang=en) by CERIT-SC, part of the Institute of Computer Science at Masaryk University.

## Data Availability
The GitHub repository is unable to host Git-annexe-managed data. The only data really missing is `inputs/raw/CZV-2025_testovaci_data_MAFIL.zip` archive. This file is available to the SVDR01 course attendees. All the other files can be extracted or recomputed using DataLad from the dataset repository contents at GitHub or re-downloaded from DockerHub.
